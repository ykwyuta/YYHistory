# 必要な画像の一覧

このファイルは `src/images.rs` から生成しています（手で編集しないでください）。人物や出来事を追加すると、必要な画像もここに増えます。

画像は `assets/images/` の下に、表のパスのとおりに置きます。置いた画像の抜け・サイズ違い・余分なファイルは `npm run images:check` で確かめられます。画像が無いあいだは、ゲームはこれまでの図形の絵で表示します。

## 時代考証の約束

- 教育用のため、各画像の説明と、ゲーム内の人物・出来事の本文と史料に合わせる。書かれていないこと（人物の表情や持ち物、群衆の人数など）を事実のように強調しない。
- 服装・建物・道具は、その年代と地域のものにする。後世の建物や、その年より後に生まれたものを描かない。
- 同時代の肖像・像が残らない人物（紫式部、清少納言、カルプルニア、マリンツィンなど）は想像図になる。ゲームでは画像に「イメージ」と表示する。
- 暴力や死の場面（暗殺、虐殺、処刑など）は、直接の描写を避ける。
- 画像の中に文字を入れない（名前や題はゲームが表示する）。
- 他人の作品や写真をそのまま使わない。博物館の画像を使う場合は、利用条件を確かめて `docs/sources.md` に出典を書く。
