# 資料と復元表現

各出来事の年、地点、解説、参照URLは `src/history.rs` の `EVENTS` に記録しています。球戯場の誓いはヴェルサイユ宮殿の資料、アポロ11号はNASA、独立宣言は米国国立公文書館などを参照しています。

この初版は短い解説と探索のためのデータです。多くの項目では博物館・遺産機関の概説ページを案内しており、一つの一次史料だけで全解説を裏づけるものではありません。年単位の概数や伝承に基づく年代には本文で注記しています。人々の服装、街並み、建築の細部、群衆の配置はゲームのための創作です。

自然地理はNatural Earthの現在の海岸線を利用します。都市の座標は現場の精密な位置ではなく、地域への案内として丸めています。アポロ11号は月面の場所を地球上に置かず、ヒューストンの地上管制を撮影する項目として収録しています。

勢力の有効年は主要な政権の存在期間のおおよその目安です。楕円形は領土データに基づく境界線ではなく、勢力の位置を探すための案内です。勢力の伸縮、分裂、複数国家の関係は今後の拡充対象です。
