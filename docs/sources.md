# 資料と内容の扱い

人物・出来事・場所のデータは `src/history.rs` にあります。各人物と出来事には、根拠とした史料の名前を `source` として記録し、ゲームと図鑑に表示しています。解説文は史料と標準的な研究に基づく独自の要約です。

## 書き方の約束

- **年の数え方**：負の年は紀元前。0年はありません。
- **和暦**：月日は当時の暦（旧暦）のまま書き、西暦は年だけを添えます。旧暦の年末の日付は、西暦では翌年の1月になることがあります（例：藤原道長の没年は万寿4年12月で、西暦では1028年1月）。
- **唐の年号**：天宝3載（744年）以降は「年」でなく「載」と書かれたため、そのように表記しています。
- **不確かなこと**：生没年不詳・推定（「頃」）、諸説ある日付、史料による食い違い（モクテスマ2世の死因など）、後世の創作で広まった言葉（「ブルトゥス、お前もか」、「パンがなければお菓子を」など）は、本文で明記しています。
- **人物の言葉**：史料にある事実を一人称で語らせる教材上の再構成です。「」で示した史料の引用を除き、実際の発言ではありません。人物を配置した場所は、その人物にゆかりのある場所です。
- **地図**：位置関係を示す概略図です。川・丘・城壁・道の形、建物の位置と大きさ、場所どうしの距離は簡略化しています（パリとヴェルサイユの距離は縮めて描いています）。世界地図の海岸線はNatural Earthの現在のデータです。
- **人物の絵**：肖像画の代わりに、名前の頭文字の紋章を表示します。

## 訂正の手順

1. `src/history.rs` の該当する `Person` または `Event` を直す（`id` は保存データに使うので変えない）。
2. `cargo test --lib --features headless` で整合性の検査を通す。
3. 根拠となる史料を `source` に書く。
